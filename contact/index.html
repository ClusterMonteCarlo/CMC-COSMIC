Contact Team CMC

Open a GitHub Issue

The easiest way to ask a question or notify us of any bugs is to post an issue on GitHub, in the issue page of the repository. This is particularly helpful for code related bugs or other issues. The more information you can provide when you open an issue, the more likely we can be helpful.l

For issues with the initial conditions, open an issue on the COSMIC GitHub account here

Contact us Directly

For access to the CMC slack, where you can ask us questions directly, send an email to Carl Rodriguez.
